## 2. Algorithm Design（每项均记录依据与假设）

| 规则 | 实现 | 依据 |
|------|------|------|
| 阴阳遁 | 冬至(含)→夏至前阳遁；夏至(含)→冬至前阴遁 | 既有代码 + 测试 `test_dun_type_boundary` |
| 三元 | 公历日号 1-10/+0, 11-20/+3, 21-30/+6 | 既有代码 + `test_triple_offset_correct`；**假设**：拆补法按日近似，未实现超神接气/置闰法 |
| 局数 | `((节气基本局-1)+三元偏移)%9+1` | 既有公式 |
| 地盘 | 阳遁顺布、阴遁逆布；阴遁 n 局甲子戊在 (10-n) 宫 | **修复**：旧代码阴遁仅 ju=1 正确（错误公式 `(n+7)%9+1`），已按经典规则修正 |
| 值符 | 值符星=旬首六仪宫地盘星；随时干落时干宫；时干为甲时以遁藏仪取宫 | **假设**（无项目依据），经经典例核验：阳遁一局庚午时值符天蓬落震三宫 ✓ |
| 天盘 | 地盘按 `(时干宫-旬首宫)%9` 顺转（值符带旬首仪飞到时干宫） | **假设**；与值符随时干几何自洽 |
| 值使 | 值使门=旬首宫门，随时支：本宫起阳顺/阴逆，步数=`(时支-旬首支)%12` | **假设**；经典例核验：阳遁一局甲子旬休门 甲子坎一→乙丑坤二→…→戊辰中五寄坤二 ✓ |
| 九星/八门/八神 | 星随天盘顺转；值使落宫后门按洛书序顺布（跳过中宫）；值符神随值符宫顺布 | **假设**；天禽参与转盘（简化，不寄宫） |
| 空亡 | 时柱旬空二支→宫位（坎子/艮丑寅/震卯/巽辰巳/离午/坤未申/兑酉/乾戌亥） | **假设**；干支规则独立可验证 |
| 中宫 | 值符/值使落中宫寄坤二宫 | **假设**（常见派别） |
| 真太阳时 | 有 born_location 时用 `core.solar_time` 定时辰；日期/日干支用钟表日 | 复用 solar_time.py，未重实现 |
| 节气边界 | 扫描 y-1..y 全部 24 节气取最后一个 ≤ 时刻 | **修复**：旧代码 1 月 1 日~小寒前 KeyError |

另修复：`board.solar_term` 现为管辖遁局的节气（原为八字节界，语义不符）。晚子时不换日柱（假设）。
