# Qimen D2 Impact Analysis — 三元划分规则

> **状态**: 分析文档 — Phase 5.3
> **目的**: 评估未来将 D2（三元划分）从"日号近似"替换为"真拆补法"的全部影响。
> **结论先行**: D2 当前**保持 Deferred**（不修改、不冻结）。本分析为未来
> 替换决策提供依据。

---

## 1. 当前日号三元规则说明（D2 现状）

- **规则**：`triple_offset = ju_from_day_of_month(day_of_month)`：
  - 日号 1-10 → 上元 → 偏移 0
  - 日号 11-20 → 中元 → 偏移 3
  - 日号 21-30 → 下元 → 偏移 6
- **作用位置**：`局数 = ((节气基本局 - 1) + 三元偏移) % 9 + 1`
- **特征**：与节气时刻、日干支完全无关；仅依赖公历日号。每 10 天切换一次元，
  每节气约 1.5 个元（不等长），与节气边界不对齐。
- **冻结状态**：Deferred（`QIMEN_RULE_DECISION.md` §3）——行为即工程基线，
  但冻结状态延迟。

---

## 2. 真拆补法可能影响范围

主流拆补法核心要素（与本实现差异点）：

| 要素 | 当前（日号近似） | 真拆补法 |
|------|------------------|----------|
| 元判定依据 | 公历日号 1-10/11-20/21-30 | 日干支符头（甲子/甲午/己卯/己酉 为上元），上元起于符头日 |
| 节气对齐 | 无（纯日号） | 每节气 15 天 = 上/中/下元各 5 天，以节气时刻为界 |
| 超神/接气 | 无 | 符头日早于节气时刻 → 超神（用本节气下元或置闰）；节气先到 → 接气（用下节上元） |
| 结果 | 偏移 ∈ {0,3,6} 按日号 | 偏移由符头决定，同一日号在不同节气可能不同元 |

**影响传导链**（若替换 D2）：

```
三元偏移 → 局数 → 地盘 → 天盘(offset) → 值符星/值符落宫 → 值使本宫/落宫
        → 八门/八神排布 → 三奇落宫
```

**不受影响**：时干支（五鼠遁）、旬首、空亡（时柱旬空）、真太阳时、
中宫寄宫逻辑、盘面 Schema。

## 3. 受影响 Golden Vector

**全部 21 个向量**的以下字段受影响（`docs/qimen/golden_vectors.json`）：

- `expected_board.ju`、`triple_offset`、`day_of_month` 语义
- `expected_board.cells[].earth_plate`（地盘随局数重布）
- `expected_board.cells[].sky_plate` / `nine_stars` / `eight_doors` /
  `eight_gods` / `three_qi`（天盘/值符/值使随地盘连锁变化）
- `is_void` 与 `plan` 中不依赖局数的部分不变

| 向量组 | 影响程度 |
|--------|----------|
| G1/G2/G3 | 全部盘面字段（ju 依赖 D2） |
| Y_ju1~Y_ju9（阳遁 1-9 局） | 局数可能改变 → 地盘/天盘/值符/值使全变 |
| Z_yin2/Z_yin5/Z_yin3（阴遁） | 同上；"值符落中宫"等特殊条件可能不再成立 |
| B_*（边界/时辰向量） | ju 与盘面全变；"节气切换前后"的局数对比需重算 |
| 空亡/时干支相关断言 | 不变 |

**注**：向量中 `plan` 字段（时干支/旬首/空亡）不受 D2 影响，可复用。

## 4. 如果未来替换，需要迁移哪些测试

替换 D2 后必须同步更新的测试（`tests/test_qimen.py`）：

| 测试 | 影响 |
|------|------|
| `test_triple_offset_correct` | **失效** — 日号偏移断言直接违反拆补法 |
| `test_ju_1_to_9_coverage` | **失效** — 局数期望表需按拆补法重算 |
| `test_golden_vectors_full_board` | **失效** — 21 个向量全量重生成 |
| `test_golden_metadata_validation` | engine/rule_set version 必须递增（0.3.0 → 0.4.0） |
| `test_frozen_rule_regression` | F2 (D3) 公式保留，但偏移输入源变更 → 断言需复核 |
| 节气边界测试（冬至/夏至/立春） | 局数断言需按新三元重算 |
| `test_invariant_sweep_full_year` | 不变量本身不受影响（结构性），可保留 |

**替换流程（必经 ACP）**：
1. 裁定流派（拆补法/置闰法）与符头规则
2. 修改实现 + 递增 `QimenEngine.version`（0.3.0 → 0.4.0）
3. 重新生成全部 Golden Vectors（本文件 + 测试常量）
4. 更新 `QIMEN_ALGORITHM_ASSUMPTIONS.md` / `QIMEN_RULE_DECISION.md`（D2 → Freeze）
5. 新增拆补法特征用例：符头日、超神（符头先于节气）、接气（节气先于符头）
6. 全量回归

## 5. 成本评估（供决策参考）

| 维度 | 评估 |
|------|------|
| 实现复杂度 | 中（~60 行：符头查找 + 超神接气判定；无历法依赖新增） |
| 向量迁移成本 | **高**（21 向量全量重生成 + 人工核验） |
| 测试迁移成本 | 中~高（6+ 测试更新） |
| 与 Reference Runtime 对齐 | 当前 Reference 无奇门域；未来对齐时以冻结规则为基线 |
| 收益 | 与主流排盘软件结果一致（当前日号近似与主流存在系统性差异） |
| 风险 | 流派内部仍有差异（置闰/茅山/拆补细节），需二次裁定 |
