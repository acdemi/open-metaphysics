# BaZi Algorithm Assumptions

> **状态**: Draft — Phase 6.2 Algorithm Stabilization（确定性计算基础准备）
> **性质**: 记录当前 `BaziEngine`（v0.1.0）的每一个确定性假设。
> **约束**: 本文档**不修改任何算法**；仅显式化既有行为，供规则裁定与
> Golden Vector 设计使用（对齐 Qimen `QIMEN_ALGORITHM_ASSUMPTIONS.md` 模式）。
> **日期**: 2026-08-09

## 1. 规则假设表（B1 ~ B6）

| ID | Rule | Current Implementation | Alternative | Risk |
|----|------|------------------------|-------------|------|
| **B1** | 年柱边界（Year boundary） | 以**立春**为年界：`bazi_year_index` 在 **UTC 时刻**比较 `born_at >= lichun_time(year)`；年干支序号 = `(立春年 - 4) % 60`（1984 甲子 = 0） | 以本地时区时刻比较立春（部分地区 2/4 早 23:xx 差一天）；以农历正月初一为年界（民俗派） | 低-中：立春时刻恰逢 23:00~00:00 本地时区窗口时，UTC 判定与本地判定可能差一年；须显式裁定 |
| **B2** | 月柱/节气（Month pillar） | 以 **12 节**（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）为月界，**不使用中气**；月支 = 节固定地支；月干 = **五虎遁** `(年干×2+2+(月支-2)) % 10`；边界比较在 UTC 时刻 | 以中气分月（部分流派）；真节气交接时刻按本地时区折算 | 低：12 节为子平主流；UTC 边界比较与 B1 同风险 |
| **B3** | 日柱（Day pillar） | 干支日序 = `(JDN + 49) % 60`（JDN 为整数日数）；**23:00 本地时间换日**（`local.hour >= 23` → 次日干支） | 0:00 换日（子初换日）；子时换日随子正（0:00）；**Qimen D14 裁定为晚子时不换日柱**（跨域分歧，见 §3） | 中：晚子时（23:00-24:00）日柱归属是经典流派分歧；本实现与 Qimen 相反，须显式声明 |
| **B4** | 时柱（Hour pillar） | 时辰 = `((local.hour + 1) // 2) % 12`（子时 = 23:00~00:59）；时干 = **五鼠遁** `(日干×2 + 时支) % 10`；本地时间（zoneinfo） | 真太阳时定时辰（Qimen D13 使用 core.solar_time）；子初/子正划分派 | 中：不使用真太阳时（与 Qimen 不同）；时区错误输入将产生不同时辰 |
| **B5** | 大运（Da Yun） | 顺逆 = (年干阳 ∧ 男) ∨ (年干阴 ∧ 女) 则顺，否则逆；起运 = `round(距最近节边界天数 / 3)`（**Python banker's rounding**，`max(0, …)` 钳制）；每步 +10 年，步数默认 8（可配 `dayun_count`）；`start_at` 用 `replace(year=+n)`（2/29 → 2/28） | 起运按 3 天=1 年余数进位/舍位；四舍五入取整；以精确节气时刻差计算 | 中：`round()` 银行家舍入（.5 取偶）为隐式假设；起运日 2/29 降级 2/28；需向量锁定 |
| **B6** | 性别 / UNKNOWN | `Gender.UNKNOWN` 在大运方向判定中**按非女处理**（等价男），且输出 `gender_assumed=True`；`Gender.MALE/FEMALE` 正常 | UNKNOWN 直接报错；UNKNOWN 走默认顺运 | 低：回退策略已测试（`test_gender_assumed_flag`）；契约化时须将该回退显式写入条款 |

## 2. 基础设施假设

| 项 | 当前行为 | 说明 / 风险 |
|----|----------|-------------|
| **时区** | `born_at` 必须 tz-aware（`AgentInput` 校验）；本地时区优先取 `born_location.timezone`（ZoneInfo），回退 `born_at.tzinfo`，再回退 UTC | 时区缺失/非法时静默回退 UTC，可能改变日/时柱 |
| **真太阳时** | **不使用**（仅 Qimen D13 使用 `core.solar_time`） | 显式差异：八字不修正经度均时差；契约须声明"钟表时"为标准 |
| **午夜边界** | 日柱 23:00 换日（B3）；子时 = 23:00~00:59（B4） | 晚子时行为与 Qimen D14（不换日）跨域不一致，属既定分歧 |
| **闰月** | **不适用**：八字计算纯太阳历（节气），不依赖农历；`solar_to_lunar`（sxtwl）仅供紫微等域 | 无闰月路径 → 无闰月风险 |
| **历法依赖** | `core/calendar.py`（Meeus 截断，黄经精度 ~0.01° < 1 分钟）；`solar_terms_for_year`/`_month_boundaries` 使用 `lru_cache`（纯缓存，不影响确定性）；**compute() 不导入 sxtwl** | 节气时刻精度 ~1 分钟内（`solar_term_precision: "approx_1min"`）；缓存不影响结果 |
| **边界比较** | 年/月边界均在 **UTC 时刻**比较（B1/B2） | 与本地时区判定差异仅在边界时刻 ±数小时，向量需覆盖 |

## 3. 跨域分歧记录（与 Qimen 对照）

| 项 | BaZi（本域） | Qimen（契约 v1.0.0） |
|----|--------------|----------------------|
| 晚子时日柱 | 23:00 **换日**（B3） | **不换日**（D14 裁定） |
| 真太阳时 | **不使用**（钟表时） | **使用**（D13, 有坐标时） |
| 节气边界比较 | UTC 时刻 | UTC 判定（D1, 同机制） |

> 分歧为**既定行为**，非缺陷；契约化时必须各自独立声明，互不影响。

---

## 4. 结论

当前实现共 6 条确定性规则假设 + 6 项基础设施假设。全部为可复现、可测试的
确定行为。**需显式裁定**（对齐 Qimen D2/D14 政策裁定模式）:
- B1/B2: UTC 边界比较
- B3: 晚子时换日（跨域分歧）
- B4: 不使用真太阳时
- B5: banker's rounding 起运
- B6: UNKNOWN 按男处理

裁定记录见 `docs/bazi/BAZI_RULE_DECISION.md`（Draft, 未冻结）。
