## 2. 覆盖设计

### 2.1 Calendar Boundary（5 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-CB-1 立春前 | 2024-02-04 00:00 UTC（立春前） | 年柱 = 癸卯（9,3）；month = 寅月前（丑月, 小寒） |
| V-CB-2 立春后 | 2024-02-04 09:00 UTC（立春后） | 年柱 = 甲辰（0,4）；month = 寅月 |
| V-CB-3 立春时区敏感 | 立春时刻 ±2h 本地（东八区 2024-02-04 23:xx 附近） | 锁定 UTC 判定行为（B1 裁定） |
| V-CB-4 节过渡 | 惊蛰时刻 ±2h（2024-03-05 前后） | 月支 寅→卯 + 月干按五虎遁 |
| V-CB-5 岁末节序 | 12 月末/1 月初（小寒前后） | 月支 子→丑 + 年干跨年五虎遁 |

### 2.2 Time Boundary（4 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-TB-1 晚子时前 | 22:59 本地 | 日柱当日 + 时支 亥 |
| V-TB-2 晚子时后 | 23:00 本地 | 日柱次日（B3 换日）+ 时支 子 |
| V-TB-3 子时五鼠遁 | 00:30 本地 | 子时 + 五鼠遁时干（按日干） |
| V-TB-4 时辰窗边 | 01:00 / 02:59（丑时边界） | 时支边界准确（`((h+1)//2)%12`） |

### 2.3 Location（3 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-LC-1 时区差 | 同一时刻 UTC, born_location=Asia/Shanghai vs UTC | 日/时柱按本地（东八区）不同 |
| V-LC-2 无坐标 | tz-aware born_at, 无 born_location | 回退 `born_at.tzinfo`（B 类回退路径） |
| V-LC-3 跨日时区 | 本地 23:30（UTC 15:30） | 日柱换日按**本地** 23:00 而非 UTC |

### 2.4 Da Yun（6 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-DY-1 阳男顺 | 甲/丙…年 + MALE | 大运向前（月柱后序干支） |
| V-DY-2 阴女顺 | 乙/丁…年 + FEMALE | 大运向前 |
| V-DY-3 阳女逆 | 阳年 + FEMALE | 大运向后 |
| V-DY-4 阴男逆 | 阴年 + MALE | 大运向后 |
| V-DY-5 UNKNOWN | UNKNOWN（阴年） | 按男处理（逆）+ `gender_assumed=True` |
| V-DY-6 舍入边界 | 距节 = X.5 天 | banker's rounding 结果（.5 取偶, 显式锁定 B5） |

### 2.5 Edge Cases（4 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-EC-1 闰月 | 闰月期间的公历日期（如 2023-05 闰二月后） | 无影响（太阳历, 月柱按节气）—— 锁定 N/A 行为 |
| V-EC-2 干支奇偶 | 随机 3 日 | 日柱 stem/branch 奇偶一致（parity 不变式） |
| V-EC-3 大运步数 | dayun_count=10 | 输出 10 步, 每步 +10 岁 |
| V-EC-4 起运日期 2/29 | 生于 2/29 附近 | `start_at` 降级 2/28 行为锁定 |

### 2.6 基准参照（2 vectors）

| 向量 | 输入 | 断言 |
|------|------|------|
| V-REF-1 经典例 | 1985-08-15 10:00 Asia/Shanghai MALE | 乙丑年/申月/日×/巳时 + 完整十神/纳音/大运（现测试用例升级） |
| V-REF-2 全字段 | 与 V-REF-1 同输入两次运行 | 逐字节一致（确定性, 对齐 QC-001） |
