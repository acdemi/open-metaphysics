## 1. Ziwei ↔ BaZi 差异登记

| # | 维度 | Ziwei（当前实现, Draft） | BaZi（契约 v1.0.0 Frozen） | 性质 |
|---|------|--------------------------|------------------------------|------|
| ZB-01 | 晚子时（23:00-24:00） | **无换日逻辑** —— 农历日 = 本地民用日期（sxtwl） | **23:00 换日**（BC-004） | 真实差异; Ziwei 契约化时须转为显式裁定（歧义 A-3） |
| ZB-02 | 真太阳时 | 不使用（钟表时, ZW-003） | 不使用（钟表时, BC-005） | **一致** |
| ZB-03 | 年干/立春界 | 复用 `bazi_year_index`（同一原语, 立春 UTC 比较） | BC-002 同原语 | **一致**（共享原语, 契约化时引用） |
| ZB-04 | 五虎遁 | 同公式（ZW-006） | BC-003 同公式 | **一致** |
| ZB-05 | 时辰公式 | 同 `((h+1)//2)%12`（ZW-003） | BC-005 同公式 | **一致** |
| ZB-06 | 时区回退链 | `location.tz → born_at.tzinfo`（**无 UTC 兜底**, 静默） | `location.tz → born_at.tzinfo → UTC`（BC-012, 有兜底） | **链定义差异**（因 born_at 强制 tz-aware 行为等价; 契约化时显式声明, D-ZW-2） |
| ZB-07 | 历法依赖 | **sxtwl**（农历, 编译库, compute() 内唯一外部依赖） | compute() **无 sxtwl**（纯太阳历） | 真实差异（ZW-004 锁版为契约化前置） |
| ZB-08 | 性别 | **未被 engine 使用**（ZW-017） | 大运方向使用（BC-009/011） | 真实差异（域输入语义不同） |
| ZB-09 | 输出对象 | ZiweiChart（12 宫 + 主星） | BaziChart（四柱 + 大运） | 域对象差异（非冲突） |

## 4. 框架级边界（通用, 非 Ziwei 专属）

| 项 | 声明 |
|----|------|
| 确定性 | 所有域: 相同输入 ⇒ 字节级相同输出（QC-001 通用语义） |
| 领域边界 | 所有域只产生**确定性观测**; 解释/建议/叙述/评分/LLM/RAG/Consensus 在域外（ARCHITECTURE.md §1） |
| 契约优先 | 域间若有表面冲突, 以**各自冻结契约**为裁判, 不互相覆盖 |
| 变更通道 | 任何域行为变更 = ACP + 契约版本递增 + 向量迁移（CAPABILITY_LIFECYCLE.md §5） |

## 5. 使用规则

1. 跨域对照测试**不得**断言域间输出一致; 只断言各自契约规定的行为。
2. 差异被误报为 bug 时, 引用本登记 ZB-01/ZB-06/ZQ-01 作为判定依据。
3. Ziwei 侧差异在 Phase 6.7.3 Freeze Review 前保持 Draft; 冻结后修改须 ACP。
4. 本登记**不修改**任何 Qimen/BaZi 工件（ZERO TOUCH 约束）。
