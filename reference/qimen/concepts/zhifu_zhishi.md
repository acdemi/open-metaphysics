# 概念：值符与值使（Zhi Fu & Zhi Shi）

> 契约条款: [QC-007](../../../docs/specification/QIMEN_BEHAVIOR_CONTRACT.md) / QC-008
> 流派记录: [schools.md](schools.md)

## 时干支基础

- 日干支：`sexagenary_day_index(钟表日)`（晚子时不换日，见 schools.md）
- 时支：本地（真太阳）时辰，2 小时一辰：
  子(23-01) 丑(01-03) 寅(03-05) 卯(05-07) 辰(07-09) 巳(09-11)
  午(11-13) 未(13-15) 申(15-17) 酉(17-19) 戌(19-21) 亥(21-23)
- 时干：五鼠遁（甲己日起甲子，乙庚日起丙子，丙辛日起戊子，
  丁壬日起庚子，戊癸日起壬子）
- 旬首：时干支所属六甲旬（甲子 甲戌 甲申 甲午 甲辰 甲寅），
  所遁六仪：戊 己 庚 辛 壬 癸

## 值符（QC-007）

| 项 | 规则 |
|----|------|
| 值符星 | 旬首六仪所在地盘宫之九星（旬首在中宫 ⇒ 天禽） |
| 值符落宫 | 时干所在地盘宫（时干为甲 ⇒ 旬首宫） |
| 值符神 | 八神之首，落值符宫（中宫 ⇒ 寄坤二宫） |
| 八神布列 | 顺时针顺布（阴阳遁同向，跳过中宫） |

## 值使（QC-008）

| 项 | 规则 |
|----|------|
| 值使门 | 旬首宫地盘八门（旬首在中宫 ⇒ 坤二宫死门） |
| 落宫 | 从本宫起，阳遁顺行 / 阴遁逆行，步数 = `(时支序 - 旬首支序) mod 12` |
| 中宫 | 落中宫 ⇒ 寄坤二宫 |

```
zhi_shi_palace = (home - 1 ± steps) mod 9 + 1      # 阳 + / 阴 -
steps = (hour_branch - xun_shou_branch) mod 12
```

## 经典例（独立核验锚点）

- 阳遁一局 庚午时：值符天蓬落震三宫
- 阳遁一局 甲子旬 休门逐时顺行：甲子坎一 → 乙丑坤二 → 丙寅震三 →
  丁卯巽四 → 戊辰中五（寄坤二）

## 可观察输出

- `eight_gods == "值符"` 所在宫 = 值符落宫（寄宫后）
- 值使门所在宫 = 值使落宫
