# 概念：空亡与中宫（Void & Central Palace）

> 契约条款: [QC-013](../../../docs/specification/QIMEN_BEHAVIOR_CONTRACT.md) / QC-014
> 流派记录: [schools.md](schools.md)

## 空亡（QC-013）

时柱旬空二支 → 宫位映射：

| 六甲旬 | 空亡支 | 落宫 |
|--------|--------|------|
| 甲子 | 戌 亥 | 乾六 |
| 甲戌 | 申 酉 | 坤二 + 兑七 |
| 甲申 | 午 未 | 离九 + 坤二 |
| 甲午 | 辰 巳 | 巽四 |
| 甲辰 | 寅 卯 | 艮八 + 震三 |
| 甲寅 | 子 丑 | 坎一 + 艮八 |

地支 → 宫位（后天八卦配支）：

```
坎一: 子        艮八: 丑寅      震三: 卯        巽四: 辰巳
离九: 午        坤二: 未申      兑七: 酉        乾六: 戌亥
中五: 无支
```

- 空亡宫 1~2 个（两支可同宫，如 戌亥 → 乾六）

## 中宫（QC-014）

| 情形 | 规则 |
|------|------|
| 宫位 | 仅 palace 5 `is_central=True`；中宫无八门八神 |
| 值符落中宫 | 八神值符**寄坤二宫** |
| 值使落中宫 | **寄坤二宫** |
| 旬首在中宫 | 值使门取坤二宫（死门） |
| 天禽星 | 不寄宫（参与转盘，见 [stars_doors_gods.md](stars_doors_gods.md)） |

## 可观察输出

- `is_void` 恰 1~2 宫
- `is_central` 恰 1 宫（palace 5）
- 值符/值使寄宫行为经 4 向量锁定（G3, Y_ju1, Z_yin2, Z_yin5）
