# 概念：天地盘（Plates）

> 契约条款: [QC-005](../../../docs/specification/QIMEN_BEHAVIOR_CONTRACT.md) / QC-006
> 流派记录: [schools.md](schools.md)

## 地盘（Earth Plate，QC-005）

六仪三奇按局数布于九宫：

- 布列顺序（固定）：戊 己 庚 辛 壬 癸 丁 丙 乙
- 阳遁顺布：阳遁 n 局，甲子戊在 n 宫，依次顺行
- 阴遁逆布：阴遁 n 局，甲子戊在 (10-n) 宫，依次逆行

| 遁 | 甲子戊位置 | 方向 |
|----|------------|------|
| 阳遁 n 局 | n 宫 | 顺行 |
| 阴遁 n 局 | (10-n) 宫 | 逆行 |

不变量：9 宫各恰一干，集合 = {戊己庚辛壬癸丁丙乙}，互异。

## 天盘（Sky Plate，QC-006）

- 值符星 = 旬首六仪所在地盘宫之九星（六甲隐遁：甲子→戊 … 甲寅→癸）
- 值符随时干：时干所在地盘宫 = 值符落宫
- 天盘 = 地盘按 `(时干宫 - 旬首宫) mod 9` 偏移**顺转**
- 值符宫天盘干 = 旬首所遁之仪
- 时干为甲（旬首时辰）时，时干宫 = 旬首宫

```
sky_plate[p] = earth_plate[(p-1 - offset) mod 9 + 1]
offset = (时干宫 - 旬首宫) mod 9
```

不变量：天盘干集合 = 地盘干集合；值符宫天盘干 = 旬首仪。

## 依赖链

```
局数(QC-004) → 地盘 → 旬首宫 → 值符星/天盘偏移(QC-006)
            ↘ 时干宫 = 值符落宫
```

## 可观察输出

- 每宫 `earth_plate` / `sky_plate` 各恰一干
- 值符宫（`eight_gods == "值符"`）天盘干 = 旬首仪
