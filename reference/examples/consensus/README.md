# Consensus Examples

Consensus golden examples are auto-generated by `export_consensus_contract()`
in `reference/consensus_builder.py`.

Unlike Rule/Pattern/Knowledge examples (which use YAML), Consensus input
is `Evidence[]` -- a Pydantic model produced by the Evidence Layer.

The golden examples live in:
  `reference/contracts/consensus_contract.json`

To regenerate:
```bash
python -c "from reference.consensus_builder import export_consensus_contract, CONSENSUS_CONTRACT_PATH; export_consensus_contract(output_path=str(CONSENSUS_CONTRACT_PATH))"
```
