# 技术决策：Bazi 解释器 Prompt 方案

**决策**：采用 **结构化 SOP Prompt + Few-Shot 快查表**，而非自由零样本推理。
**原因**：防止 LLM 胡乱推算“旺衰”和“用神”，将其严格限制为“翻译官”角色。
**Prompt 组成**：
1. System Prompt：固定角色 + 铁律 + 分析四步法（定格取用 → 气势流通 → 十神精析 → 大运介入）。
2. User Prompt：动态渲染 Jinja2 模板，注入 `BaziChart` 的 JSON 结构化数据。
3. Contextual Aid：动态拼接“十神生克快查表”和“格局判定核心”，作为 RAG 未命中时的后备上下文。
