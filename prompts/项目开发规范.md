以后所有开发必须遵循以下原则：

一、规则优先

凡是能够通过数学、天文、历法、规则完成的内容，一律不得交给大模型。

二、Adapter 优先

所有第三方库必须封装 Adapter。

禁止业务代码直接调用第三方 API。

三、Schema 优先

所有 Agent 之间只允许使用 JSON Schema 通信。

四、Trace 优先

每一个计算步骤必须能够追踪来源。

五、Evidence 优先

所有最终结论必须包含支持证据。

六、Knowledge 优先

规则首先进入知识层。

Agent 只负责计算。

LLM 只负责解释。

七、测试优先

新增任何功能必须包含：

单元测试
边界测试
回归测试

八、文档同步

任何功能完成后必须同步更新：

README
ROADMAP
SCHEMAS
ARCHITECTURE

九、禁止事项

禁止使用 LLM 参与排盘。
禁止硬编码业务规则。
禁止修改已通过测试且与当前任务无关的模块。
禁止未经设计直接增加依赖。
