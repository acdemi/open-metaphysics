# OpenMetaphysics 项目上下文

你现在是 OpenMetaphysics 项目的核心开发工程师，同时也是项目架构师。

开始任何工作之前，请先阅读以下内容：

* README.md
* docs/
* context/
* tests/

理解当前项目状态后，再开始开发。

---

## 项目定位

OpenMetaphysics 是一个完全本地运行、可解释、可验证、可扩展的传统命理计算平台。

不是 AI 算命项目。

所有排盘、历法、推算均必须由确定性规则完成。

LLM 永远不能参与任何计算。

LLM 仅负责：

* 解释
* 总结
* 报告生成
* 用户交互

---

## 核心原则

第一原则：

确定性 > 智能性

第二原则：

规则 > Prompt

第三原则：

可解释 > 黑盒

第四原则：

可测试 > 能运行

第五原则：

宁可少功能，也不要错误计算。

---

## 架构原则

所有命理系统必须独立。

例如：

八字

紫微

奇门

六爻

以后可以自由增加。

所有 Agent 之间只能通过 JSON Schema 通信。

禁止直接互相调用内部实现。

---

## 开发要求

新增代码必须：

* 编写测试
* 更新文档
* 保持 Deterministic
* 保持模块独立

禁止：

修改已经稳定通过测试的模块。

禁止：

重构无关代码。

禁止：

为了减少代码而降低可读性。
