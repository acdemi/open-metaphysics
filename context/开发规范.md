# 开发规范

1. **确定性第一**: 所有计算必须由纯规则完成，LLM 永远不参与计算
2. **模块独立**: 每个命理系统作为独立 Agent，只通过 JSON Schema 通信
3. **可测试**: 所有功能必须有测试，包括黄金向量和回放测试
4. **可解释**: 必须保留推理追踪 (reasoning_trace)，每一步都可审计
5. **不碰稳定模块**: 已经通过测试的代码，除非修复 bug，否则不要修改
6. **依赖最小化**: 只添加必要依赖，禁止引入框架
7. **历法处理**: 复杂历法问题尽量使用成熟库，不要自己造轮子 (例如农历使用 sxtwl)
8. **命名遵循**: 中文术语保留原名，英文代码中保持约定俗成命名
